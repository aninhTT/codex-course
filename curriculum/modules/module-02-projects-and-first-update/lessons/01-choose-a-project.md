# Lesson 2.01: Give your work a project

Keep the sources and conversations for your task together so next week starts with less setup.

## Learn

A **project** groups related chats, instructions, and sources. A **local project** can give the desktop assistant access to selected folders. Your **company workspace** is the organization account with its members and settings.

Use the project you need for the work. A ChatGPT project can organize uploads and connected sources. A local project can organize files on your computer. Neither requires you to become an engineer.

The course itself is already a body of work. Keep practice with its course materials, or create a separate home for a real workflow. A project name does not grant folder access; check the actual sources.

## See It

A project called “Team Updates” might hold source links, a writing template, and separate chats for each reporting period.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Name the workflow you chose in Module 1 and the sources it needs.

2. In Work, create or select a project with those sources. In Codex, select the course project or a local folder for this workflow.

3. Give the project a name you will recognize next week. Add the needed sources, rather than unrelated work files.

4. Start a chat for one outcome, such as “Draft this week’s update.” Ask which sources it can read.

**Success criteria:** You have a named project and verified access to the sources for one task.

## Challenge — Optional

Start a second chat for reviewing the same workflow. Check which project context is available and what you still need to explain.

**Success criteria:** You distinguish shared project sources from another chat’s conversation history.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Bring your project name and the sources it can actually read.

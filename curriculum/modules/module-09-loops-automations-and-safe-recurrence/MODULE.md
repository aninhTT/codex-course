# Module 9: Loops, Automations, And Safe Recurrence

You already practiced the manual Ask, Inspect, Plan, Act, Review loop; now you'll design safe recurring loops.

This module keeps automation beginner-safe while still making the outcome real. The learner designs, manually tests, and schedules one low-risk recurring loop. The main artifact is an automation design card that makes the trigger, cadence, prompt, evidence, stop condition, risks, destination-app review, and owner visible before anything runs unattended.

## What You'll Learn

- how manual loops, review loops, Goal loops, thread automations, and standalone automations differ
- how to choose the smallest recurring pattern that fits the task
- how to write a durable automation prompt
- how to test manually before scheduling
- how to define stop conditions and review early outputs in the destination app
- how to schedule one read-only/report-only loop

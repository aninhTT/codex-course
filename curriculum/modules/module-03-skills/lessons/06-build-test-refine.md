# Lesson 3.06: Test your skill and combine useful methods

A skill becomes useful when it works on new material, not just the example that inspired it.

## Learn

Test with a second input, then a missing-input case. Look for copied dates, stale names, or facts carried over from the previous run.

Small skills can work together. Your workflow skill prepares the update; Clean Draft reviews its wording. Keep their responsibilities clear so a writing pass does not invent missing work facts.

A useful description also helps the assistant select the right skill. Ask for it by name first. Then try a natural request and check which skill the assistant chose. Selection can vary; verify it rather than assuming.

## See It

The sample week 2 contains a decision that week 1 did not. A correct second run reports the new decision instead of repeating the old uncertainty.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Run weekly-update-helper with week-02-notes.md after its week 1 test. For another chosen workflow, use a second input for that same skill.

2. Check changed facts, names, and dates. Then try a missing source and inspect how the skill responds.

3. Fix one weak instruction and rerun the failed case. Save a short note about the change.

4. Use Clean Draft on the new result. Keep the factual questions visible and save both the method and its tested output.

**Success criteria:** Your skill works on a second input and handles a missing source without inventing content.

## Challenge — Optional

Try a request without naming the skill. Check which method loaded and improve its description if the match is unclear.

**Success criteria:** You have evidence of explicit and natural-language use, or a clear note about the selection issue.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Bring your tested skill, second input, missing-source check, and change note.

# Lesson 3.02: Where Skill Learning Lives

## Where You Are

You know what a skill is for. Now you will clarify where this course teaches skills so the folder question does not become the lesson.

## Learn

Most of the skill learning in this course happens inside this course folder. The course contains the lesson files, practice files, learner assets, and a reserved local skill example at `learner-assets/skills/use-case/`.

A real skill for real work can eventually live somewhere else, because it may need its own files, references, scripts, or future maintenance. But for this module, do not overthink project switching. Stay in the course workspace unless Codex clearly explains why a real work artifact needs its own local folder.

Simple check:

- Am I learning the skill concept? Stay in the course folder.
- Am I practicing with course materials? Use `practice-workspace/` or `learner-assets/`.
- Am I building a real reusable asset for work? Consider a separate local folder later.

## Practice

Try this in Codex:

```text
Explain where skill learning happens in this course. Use the course folder, `practice-workspace/`, and `learner-assets/skills/use-case/` as examples. Then give me one simple rule for when a real work skill should move into its own local folder later. Do not give me project-switching scripts yet.
```

**Success criteria:** The learner understands that course skill learning stays in this folder, while real work can move into its own local folder later when needed.

## What You Made Or Decided

You decided to keep course skill learning in this course folder and save separate projects for real work that needs its own home.

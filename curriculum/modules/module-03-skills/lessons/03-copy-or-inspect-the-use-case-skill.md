# Lesson 3.03: Copy Or Inspect The Use-Case Skill

## Where You Are

You know a skill can package a repeatable process. Now you will look at a more realistic example before creating your own.

## Learn

The course reserves a local folder for the `use-case` skill:

```text
learner-assets/skills/use-case/
```

This skill helps identify AI and automation opportunities from messy work context. It asks about role, team, recurring work, pain points, blockers, source systems, and how success would be checked.

GitHub is optional. The course should not require learners to access GitHub during the lesson.

## Practice

Try this in Codex:

```text
Inspect `learner-assets/skills/use-case/`. Walk me through what the skill does and what process it follows. Focus on the beginner-relevant parts: how it finds pain points, how it gathers context, what files support it, and what it saves or produces. Keep it beginner-friendly and do not require GitHub access.
```

**Success criteria:** The learner sees or understands a realistic skill pattern before building their own.

## What You Made Or Decided

You inspected the local use-case skill location and learned why skills should gather context before producing recommendations.

## What's On Deck

Next, you will actually run the use-case skill and turn its ideas into course artifacts.

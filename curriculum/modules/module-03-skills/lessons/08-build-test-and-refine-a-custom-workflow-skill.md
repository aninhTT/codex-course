# Lesson 3.08: Build, Test, And Refine A Custom Workflow Skill

## Where You Are

You have a workflow summary from the interview. Now Codex can turn that summary into a first skill.

## Learn

Skills are easier to build well when Codex plans before it writes anything. Use the workflow summary from Lesson 3.07, review the plan, build the first version, test it with realistic scenarios, and make one useful iteration.

Stay in the course folder for the lesson unless the skill is clearly becoming real work that deserves its own local folder.

## Practice

Step 1: type this into Codex:

```text
Let's plan this custom skill before building it. Use the workflow summary from the previous lesson as the starting point. Outline the goal, trigger, inputs, steps, output, edge cases, review checks, and what is out of scope. Do not build anything yet. I want to review the plan first.
```

Step 2: after the plan looks right, type this:

```text
Now build the first version of this custom skill. Keep it focused on the workflow we planned. After building, help me test it with 2 realistic scenarios, identify what is weak, and make one useful refinement.
```

**Success criteria:** The learner reviews the plan, builds or clearly locates the skill, tests it with realistic examples, and makes one focused iteration.

## What You Made Or Decided

You built a custom workflow skill from a real pain point and tested it once.

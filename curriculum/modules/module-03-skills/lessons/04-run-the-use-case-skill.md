# Lesson 3.04: Run The Use-Case Skill

## Where You Are

You inspected the local use-case skill. Now you will run it so it gives you practical ideas to use in the rest of the course.

## Learn

This is the moment where the skill becomes useful. Instead of treating the use-case skill like a file to admire, ask Codex to follow it as a process.

For this course, keep the run lightweight:

- use your own answers first
- use voice dictation if talking through your work is faster
- let connectors stay optional and consent-based
- translate any original Claude/Cowork wording in the copied source into this course's Codex mental model
- ask Codex to save the course-facing shortlist in `learner-assets/use-case-shortlist.md`
- choose one idea that could become a small first skill

The goal is not to find the perfect use case. The goal is to leave Module 3 with practical candidates you can build from.

## Practice

Try this in Codex:

```text
Run the local use-case skill for this course. Read `learner-assets/skills/use-case/SKILL.md` and use its process to interview me about my role, recurring work, pain points, blockers, and what I would like AI to help with. When the copied source skill mentions Claude or Cowork, translate that into Codex course language: chat, course folder/project, skill, prototype or Site, and scheduled loop. Do not read connected apps unless I explicitly approve it. After the interview, give me 3 to 5 practical use-case ideas, recommend one small idea that could become my first skill, and update `learner-assets/use-case-shortlist.md` with the shortlist.
```

**Success criteria:** The learner has 3 to 5 practical use-case ideas saved in `learner-assets/use-case-shortlist.md` and one recommended first-skill candidate.

## What You Made Or Decided

You ran a real local skill and created a use-case shortlist that feeds the next build.

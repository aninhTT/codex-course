# Lesson 3.06: Build A First Practical Skill

## Where You Are

You ran the use-case skill and inspected skill structure. Now you will build a small first skill from one practical idea.

## Learn

The first skill should solve one narrow, useful problem. Use the recommendation from your use-case shortlist if it feels small and concrete enough.

If your shortlist idea is too big, use the course fallback:

- Name: `weekly-recap-helper`
- Job: turn rough notes into a cleaner weekly recap with priorities, wins, blockers, and next steps
- Starter sources: `practice-workspace/notes/weekly-review-draft.md` and `practice-workspace/templates/weekly-recap-template.md`

Keep this beginner-sized. The point is not to build the perfect skill. The point is to see how a repeated process becomes reusable and useful.

## Video Cue

Watch this walkthrough: [Skills in Codex](https://www.loom.com/share/9d713412998744c09c7c21326d05bea4).

## Practice

Try this in Codex:

```text
Help me create a beginner Codex skill from one idea in `learner-assets/use-case-shortlist.md`. Recommend the smallest practical option first. If my use-case ideas are too broad, use the fallback `weekly-recap-helper` skill based on `practice-workspace/notes/weekly-review-draft.md` and `practice-workspace/templates/weekly-recap-template.md`. Keep the skill lean, practical, and easy for a beginner to understand. Keep the work inside this course folder unless there is a clear reason not to. After creating it, summarize what files were created or changed and how I should inspect and try the skill.
```

**Success criteria:** The learner ends with a simple, focused skill draft based on a real use-case idea or the course fallback, and knows how to inspect and try it.

You built a first practical skill that packages one repeated process.

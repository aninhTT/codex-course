# Lesson 3.05: Inspect A Skill Before Building

## Where You Are

You have run the `use-case` skill and created practical ideas. Now you will learn what parts of a skill matter most before Codex creates your first one.

## Learn

Before building a first skill, inspect one. You do not need to understand every detail. You only need to see that a skill is structured instructions plus any supporting resources that help Codex do a focused job.

The main parts to notice are:

- what triggers or describes the skill
- what process Codex should follow
- what inputs Codex needs
- what output Codex should produce
- what tools, references, or scripts support the process
- what Codex should avoid or ask before doing

## Practice

Try this in Codex:

```text
Show me the main parts of a Codex skill using the local `use-case` skill folder. Focus on what matters for a beginner: purpose, process, inputs, output, boundaries, and supporting files.
```

**Success criteria:** Codex explains the main parts of a skill and the learner sees what matters for a simple first build.

## What You Made Or Decided

You know what to look for when inspecting a skill before trusting or editing it.

# Lesson 3.02: Find and download Clean Draft

Get a real working skill from the company marketplace, with the tutor handling the file work.

## Learn

Clean Draft improves a draft so a busy reader can understand it and act. It first checks structure, then sentences. It preserves facts and flags missing owners, dates, recommendations, or decisions.

Start with the [marketplace entry](https://ai-marketplace-sbqrdzy4sa-uw.a.run.app/?tool=curated%3Askill%3Aclean-draft), then its [GitHub source](https://github.com/thumbtack/shared-skills/tree/main/users/tsalman/clean-draft). Use your company GitHub account. The tutor can help retrieve the files; you do not need to learn Git commands.

Download the whole folder. Its checker lives in `scripts/prose_check.py`, so copying only SKILL.md is incomplete. Keep the source copy unchanged and customize a separate practice copy later.

## See It

“Copy the complete Clean Draft folder from the supplied GitHub source into practice-workspace/downloads/clean-draft/. Include scripts and preserve any existing copy.”

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Open the marketplace entry and GitHub source. If sign-in or repository access is missing, let the tutor help you resolve it.

2. Ask the tutor to retrieve the complete folder into your course practice area. In Work, it can use the accessible course files or its task files.

3. Find SKILL.md, README.md, VERSION, and scripts/prose_check.py. Ask what each file contributes.

4. Confirm where the copy lives and how you will use it in the next lesson.

**Success criteria:** You retrieved the full skill and located its checker, or recorded the specific GitHub access step still needed.

# Lesson 3.03: Study Clean Draft, then run it on real writing

See how a skill’s instructions change a real draft.

## Learn

`SKILL.md` contains a name, description, and the steps the assistant follows. Its description helps it recognize relevant requests. Supporting files can supply examples or a checker.

Study Clean Draft’s input, method, output, and limits. The structure pass puts the recommendation and request where readers can find them. The sentence pass removes clutter and uses plain words.

The readability checker flags wording before and after. It does not verify a date, decide who owns an action, or prove a claim. You still check facts and resolve the gaps it finds.

Use the team-update draft you saved in Module 2. If you chose a different workflow, use its draft. Keep the original for comparison.

## See It

Illustrative example from the course sample:

- **Before:** “We need someone to look at the open questions and a decision about what to do next.”
- **After:** “Decision needed: choose an owner to review the open questions.”
- **Gap for the author:** “Who should own the review, and when is it needed?”

The edit makes the request clearer while leaving the unknown owner and date for a person to resolve.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Ask the tutor to show the skill’s description and walk through its input, two editing passes, output, and missing-information rule.

2. Check the installed skills and confirm you can select Clean Draft. If not, ask the tutor to enable it or follow the instructions explicitly for this guided run.

3. Run it on your draft for a named audience. Keep original and cleaned copies. Ask the assistant to run the checker before and after.

4. Compare one structural change and one sentence change. Read the gaps and fill only those you can answer from your own knowledge or sources.

**Success criteria:** You ran Clean Draft, explained two changes, and reviewed its factual gaps. Record whether its checker ran.

## Challenge — Optional

Make a separate copy and change three useful preferences: audience, phrases to cut, or review-only behavior. Rerun the same draft.

**Success criteria:** You can explain how your custom instructions changed the output while preserving facts.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Keep the original and cleaned drafts, gaps, checker result, and any separate customization copy.

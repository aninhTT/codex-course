# Lesson 5.05: Review a run and know how to pause it

Make sure the schedule is saving attention rather than creating another thing to clean up.

## Learn

Review the first few scheduled outputs. Look for the right reporting period, current sources, useful questions, and a draft your reader could understand.

If the result is noisy or incomplete, improve the saved request or skill. Test the change before trusting repeated runs. You can pause or delete a course task when it has served its purpose.

Pages and Sites come next. Adding them does not automatically change the schedule. Start with a manual handoff: review the draft, then update the destination deliberately.

## See It

A useful run report says what period it checked, where it saved the draft, and which gaps need your attention.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Open one run in Scheduled. If the next run has not happened, inspect your manual test and the saved task settings.

2. Identify one useful result and one improvement. Update the saved prompt or skill only if there is a concrete issue.

3. Find the pause, edit, and delete controls. Decide whether to keep your practice task running during the next modules.

4. Record who reviews the next result and carry the reviewed draft into the Page activity.

**Success criteria:** You reviewed available run evidence, chose whether to keep the schedule, and know how to pause it.

## Challenge — Optional

Review two runs for repeated noise. Make one focused improvement and test it.

**Success criteria:** The change addresses an observed problem rather than simply adding more instructions.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Bring a reviewed draft, its sources, and the active-or-paused schedule decision to the Page activity.

# Lesson 5.02: Make sure the task has what it needs

A task running tomorrow needs to know where to find its sources without you pointing at them.

## Learn

A **local run** uses your computer’s files and tools. A **cloud run** uses a hosted environment with its own accessible sources. It does not automatically inherit your laptop’s folders or sign-ins.

Choose the environment based on the workflow you tested. Connected documents can be a useful source for cloud work. A local capture skill may need your computer on and the app running.

If one step needs your attention, keep it manual. Scheduling a draft from prepared inputs is still useful. Check that the actual scheduled environment can use the skill, not just the chat where you authored it.

## See It

A run that only knows “use the file I downloaded” is incomplete. Give it a specific accessible location and a rule for choosing the reporting period.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. List the sources, template, skill, and tools used in your manual sequence.

2. With the tutor, choose local or cloud and check access in that environment.

3. Test one retrieval there and identify the skill the run can actually use.

4. Keep an unsupported capture step manual and write down what you must prepare before the run.

**Success criteria:** You verified the needed sources and method in the intended environment and recorded any manual input step.

## Challenge — Optional

Move one input to a suitable connected source and test whether that removes an unnecessary local dependency.

**Success criteria:** You have an observed result showing what the new environment can access.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Bring the verified dependencies and any manual preparation step.

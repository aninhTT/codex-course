# Lesson 9.02: Explore the starter app files

Learn enough of the file structure to direct a change confidently.

## Learn

**HTML** holds page structure and content. **CSS** controls appearance. **JavaScript** supplies behavior. The starter app separates those jobs into files.

You do not need to become a developer to ask for a change. Knowing the rough map helps you review what Codex touches and describe a problem clearly.

Copy the starter into your chosen practice location before editing. Keep the original sample available for another attempt.

## See It

Changing a heading mainly affects HTML. Changing panel colors affects CSS. Adding a working filter needs JavaScript behavior.

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Ask Codex to inspect practice-workspace/starter-app/ and explain the three file types using something visible in the app.

2. Copy the app to your chosen project or playground location without replacing existing work.

3. Open index.html in a browser, or ask Codex to help you preview it locally.

4. Choose one visible element and ask which files would change if you modified it.

**Success criteria:** You opened the starter copy and can connect one visible change to the relevant file.

## Challenge — Optional

Ask for a single wording or style change, inspect the changed file, and verify it in the browser.

**Success criteria:** You can identify the change in both the file and the preview.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Keep the inspected app copy, preview method, and change you want to make.

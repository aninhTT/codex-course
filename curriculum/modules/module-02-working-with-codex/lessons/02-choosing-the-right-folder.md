# Lesson 2.02: Choosing The Right Folder

## Where You Are

You know the project is the folder Codex can work inside. Now you will make the folder system concrete.

## Learn

Folder choice affects what Codex can inspect and change. A broad folder gives Codex more context. A smaller folder keeps the work focused.

Use this course workspace when you are taking lessons. Use `practice-workspace/` for guided exercises. Use `playground/` for safe experiments. Use `reference/` when you need a quick reminder. Use `learner-assets/` to track your progress and use cases.

For most of the course, stay here. If you build something for real work that you want to keep improving, that can move into its own local folder/project later.

If you are unsure, ask Codex: "Is this course folder the right place for this task?"

## Visual Cue

```text
Course work:      this folder
Guided practice:  practice-workspace/
Free experiments: playground/
Progress notes:   learner-assets/
Quick reminders:  reference/
Real future work: a separate local folder when it deserves one
```

## Practice

Try this in Codex:

```text
Look at this course workspace and help me understand the folder choices. Explain what belongs in `curriculum/`, `practice-workspace/`, `learner-assets/`, `reference/`, and `playground/`. Then give me one simple rule of thumb for when real work should move into its own local folder/project.
```

**Success criteria:** The learner can name a broad-folder use case, a smaller-folder use case, and a no-project use case.

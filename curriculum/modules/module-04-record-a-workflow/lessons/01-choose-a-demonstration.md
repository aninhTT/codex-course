# Lesson 4.01: Choose a workflow worth showing

You have described a skill. Now try showing a task that is easier to demonstrate than explain.

## Learn

**Record & Replay** turns a demonstrated computer workflow into a skill draft. It is useful for repeated clicks, report settings, and naming preferences that are easy to forget in a written request.

Choose something you already know how to do. A short example might open a report, select a date range, and save the input for your update. Keep judgment-heavy decisions separate from routine steps.

Recording creates instructions you still need to inspect and test. Thumbtack has enabled Computer Use for this course environment; the tutor can help you use the available recording control.

## See It

“Every Friday I open the same report, select this week, and save a copy. I’ll show you the steps so we can reuse them.”

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. For the team-update path, open week 1 notes and save a current-input copy in a separate input folder. For another chosen workflow, demonstrate its equivalent preparation step.

2. Show the tutor where it starts and what a successful finish looks like.

3. Identify the values that change next time: week, report name, folder, or another input.

4. Rehearse once. Remove unrelated cleanup and stop before sending or publishing anything.

**Success criteria:** You chose a task you can demonstrate with clear changing inputs and a visible success check.

## Challenge — Optional

Compare demonstrating the task with describing it in a prompt. Choose the clearer way to capture it.

**Success criteria:** You can explain which details the demonstration makes easier to capture.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Keep the task start, finish, changing inputs, and rehearsal steps.

## Tutor Notes

Recording currently requires macOS. If the learner cannot see the control, troubleshoot once, then use reference/recording-help.md. Do not make everyone complete a separate fallback lesson.

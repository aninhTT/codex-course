# Lesson 6.02: Assemble The Workflow Starter Kit

## Where You Are

You chose one pain point. Now you will bundle the course artifacts that could help with it.

## Learn

A Codex Workflow Starter Kit is a small practical bundle. It does not need to be perfect. It should make the workflow easier to explain, review, and improve.

The kit should include:

- pain point summary
- workflow trigger, inputs, and desired output
- one prompt or skill candidate
- one prototype idea or prototype link/path
- one Goal draft if the work is long enough
- what should stay manual for now
- when this would deserve its own real project folder

## Practice

Try this in Codex:

```text
Help me assemble a Codex Workflow Starter Kit for the pain point I chose. Include: pain point summary, workflow trigger, inputs, desired output, prompt or skill candidate, prototype idea or path, Goal draft if the work is long enough, what should stay manual for now, and when this would deserve its own real project folder. Keep it practical and beginner-friendly.
```

**Success criteria:** The learner has a starter kit that pulls together the beginner course artifacts.

## What You Made Or Decided

You assembled the first version of your Codex Workflow Starter Kit.

## What's On Deck

Next, you will add review and safety checks so the kit is usable without being over-trusting.

# Lesson 6.03: Add Review And Safety Checks

## Where You Are

You assembled the starter kit. Now you will make it safer and more reviewable.

## Learn

Codex can help with a lot of the workflow, but you still own the output. A useful kit says what Codex may do, what it must ask before doing, and how a human reviews the result.

Review rules should cover:

- what evidence Codex should cite or preserve
- what actions require approval
- where the output should be reviewed
- what would make the output wrong or risky
- when the workflow should stop and ask for help

## Practice

Try this in Codex:

```text
Add review and safety checks to my Codex Workflow Starter Kit. Include what evidence Codex should use, what actions require my approval, where I should review the output, what would make the result wrong or risky, and when Codex should stop and ask for help. Keep it short enough that I would actually use it.
```

**Success criteria:** The learner has a practical review checklist for the starter kit.

## What You Made Or Decided

You added boundaries and review habits to the workflow kit.

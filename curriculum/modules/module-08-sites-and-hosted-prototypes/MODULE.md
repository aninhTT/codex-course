# Module 8: Sites And Hosted Prototypes

You already built or planned a local prototype; now you'll learn when a workflow should stay a document, become a spreadsheet, or become a hosted Site.

This module does not rebuild the prototype curriculum. Instead, it teaches the questions a learner should answer before asking Codex to save and deploy a hosted site: what should be reviewed, who should see it, whether it needs storage, and what must stay out of the source files.

## What You'll Learn

- how local preview, saved versions, and deployments differ
- how to decide whether the work should be a document, spreadsheet, local prototype, or Site
- how to think about access, secrets, environment values, and storage
- why deployment should be intentional
- how to ask Codex for a Sites-readiness review and a final deployment URL

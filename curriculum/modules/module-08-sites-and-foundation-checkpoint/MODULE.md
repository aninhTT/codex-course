# Module 8: Build a Useful Team Site

## What You Will Do

Build a small hub, improve it, and deploy a reviewed version for a chosen audience.

Recommended example: Build the Team Update Hub Site from the reviewed update, next steps, and source links.

You can use another workflow instead. Bring its corresponding result forward rather than starting a new task.

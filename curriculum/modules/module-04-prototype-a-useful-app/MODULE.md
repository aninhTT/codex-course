# Module 4: Prototype A Useful Workflow

This module turns a workflow idea into a small working surface. Learners can build the suggested pain-point prototype or use the starter app as a safer guided path.

## What You'll Learn

- what prototypes are for
- how to choose between a suggested prototype and the starter app
- how a local app is structured
- how to make one guided prototype change
- how to write your own prototype prompt using guiding questions
- how to use Plan mode before building
- how to build, preview, review, and reflect before moving into Goals

# Lesson 4.05: Use Plan Mode Before Building

## Where You Are

You wrote your own prototype prompt. Now you will ask Codex to plan before it builds.

## Learn

Plan mode is useful when a task is bigger than a quick edit. It helps Codex slow down, explain what it intends to build, name the files it expects to touch, and surface assumptions before it acts.

In Codex, use Shift+Tab to switch into Plan mode when available. Then ask for the plan. The point is not bureaucracy. It is giving you a chance to redirect before Codex builds the wrong thing.

Screenshot slot: `curriculum/assets/screenshots/plan-mode-shift-tab.png`

## Practice

Try this in Codex:

```text
I'm switching into Plan mode before building. Use the prototype prompt I drafted. Give me a beginner-friendly v1 plan with the goal, user, 2 or 3 features, sample data approach, files you expect to touch, preview method, review checklist, and what is out of scope. Do not build yet.
```

**Success criteria:** The learner has a small v1 prototype plan, a chosen project location, and clear out-of-scope boundaries.

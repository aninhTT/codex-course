# Module 5: Goals And Longer Codex Work

By now the learner has worked with files, skills, and prototypes. This module introduces Goal mode for longer work where Codex should keep working until the evidence says the job is done or honestly blocked.

## What You'll Learn

- when a normal prompt is enough
- when a Goal is useful
- what makes a Goal strong enough to verify
- how to improve a rough Goal before running it
- how to draft a bounded Goal with outcome, evidence, constraints, boundaries, iteration policy, and blocked condition

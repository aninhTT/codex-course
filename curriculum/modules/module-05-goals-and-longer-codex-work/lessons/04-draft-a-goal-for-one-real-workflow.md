# Lesson 5.04: Draft A Goal For One Real Workflow

## Where You Are

You practiced improving a rough Goal. Now you will draft one Goal for a real or sample workflow.

## Learn

Before activating a Goal, ask Codex to help shape it. The interview should answer what outcome you want, what evidence would prove it, what constraints matter, what sources Codex can use, how Codex should choose the next action, and what counts as blocked.

That interview step is the learner's steering wheel. It keeps Goal mode useful without turning it into vague momentum.

If you do not have a real Goal candidate yet, choose one of these practice options:

- create a competitive market analysis across Thumbtack competitors
- run a long audit of one project, document, or workflow
- design a large inbox cleanup or review queue with human approval before any send/archive action
- use your `use-case` skill output to pick a long-running evidence-backed workflow

## Practice

Try this in Codex:

```text
Help me draft one strong Codex Goal. If I have a real workflow candidate, interview me about it first. If I do not, offer me sample Goal options from: competitive market analysis, long audit, large inbox cleanup, or a use-case-skill-derived workflow. Then draft a Goal using the full template: desired end state, verification evidence, constraints, allowed inputs or boundaries, iteration policy, and blocked condition. Do not activate the Goal yet. End by asking whether I want to run it, save it, or leave Goal mode for later.
```

**Success criteria:** The learner ends with a Goal draft that is specific enough to verify and clear enough to review before activation.

## What You Made Or Decided

You drafted one evidence-backed Goal and decided whether it is worth running now.

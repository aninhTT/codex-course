# Lesson 10.04: Steer the work and review the evidence

Practice changing direction without losing the outcome you asked for.

## Learn

You can add context or correct a requirement while longer work continues. Explain what changed, why it matters, and which earlier instruction it replaces.

Ask for a status recap when you need one. It should separate completed outputs, supporting evidence, blockers, and next steps. The assistant’s claim that it is done still needs your review.

If you kept the Goal as a draft, practice on a short manual workflow review. Label that practice honestly rather than calling it a completed Goal run.

## See It

“Keep the source audit, but prioritize the Page and Site before the optional prototype. Show what this changes in the remaining work.”

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Request a concise status recap from your running task, or start a short manual review if you did not run the Goal.

2. Give one useful clarification and ask the assistant to explain its effect on the next step.

3. Open a claimed output and compare it with your verification criteria.

4. Record what is complete, which issues need attention, and whether to continue or stop.

**Success criteria:** You redirected a task and checked a claimed result against its evidence.

## Challenge — Optional

Ask the assistant to review its result critically, then independently check one issue it did not catch.

**Success criteria:** Your own review adds information beyond the assistant’s self-review.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Keep the checked output, clarification, and current task status.

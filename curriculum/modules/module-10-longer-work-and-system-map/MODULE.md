# Module 10: Guide Longer Work in Work or Codex

## What You Will Do

Write a checkable Goal, practice steering longer work, and improve your workflow.

Recommended example: Draft a Goal to audit the team update’s sources, copies, and review evidence.

You can use another workflow instead. Bring its corresponding result forward rather than starting a new task.

## Choose Your Surface

- **ChatGPT Work:** Use supported desktop Goal controls, or use a hosted Work request with a clear outcome and review criteria.
- **Codex:** Use supported Goal controls in Codex and inspect evidence as the work progresses. This module is not exclusive to Codex.

Use this optional module for longer work in Work or Codex. Module 9 is not a prerequisite.

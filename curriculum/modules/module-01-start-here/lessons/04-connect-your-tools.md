# Lesson 1.04: Connect your everyday tools

Let’s connect the tools you already use and get one useful answer from them.

## Learn

A **connector** gives the assistant access to a service through a plugin. You can ask for setup help in either Work or Codex. Computer Use is already enabled in the intended Thumbtack learning environment.

| Tool | A useful first task |
| --- | --- |
| Google Docs | Read a brief or create a recap. |
| Google Sheets | Check a table or update a tracker. |
| Google Drive | Find a file you need. |
| Google Calendar | Review your meetings and recurring commitments. |
| Granola | Find meeting decisions and action items. |
| Linear | Check a project or issue. |
| Gmail | Find a relevant email or prepare a reply draft. |

The Google Drive plugin may supply Docs, Sheets, and Drive together. You do not need three separate installations when one covers them. GitHub will also be useful for downloading Clean Draft in Module 3. Next, we will use Calendar, Granola, and Linear to find ideas from your actual week.

Your tutor can inspect existing connections and help install or enable the tools you choose. Complete personal sign-in yourself when prompted. A connected account still follows that service’s permissions.

## See It

“Help me connect Google Drive and Granola. Then find my project brief and the decisions from its latest meeting.”

## Practice

Your tutor guides one step at a time in Work or Codex. Continue the recommended team-update example, or adapt the steps to your saved workflow choice.

1. Ask: “Which of these tools are already connected: Google Docs, Sheets, Drive, Google Calendar, Granola, Linear, and Gmail?”

2. Pick two useful connections. Accept the tutor’s offer to help enable or install them. Complete sign-in when prompted; do not paste credentials into chat.

3. Verify each with a small task. For example: find a named Drive document and list action items from one Granola meeting.

4. Save the two useful source links with your course work. Check that the assistant retrieved the intended content.

**Success criteria:** You used two connected tools successfully, or recorded the exact connection that still needs sign-in or access.

## Challenge — Optional

Ask one question that combines two sources, such as comparing a meeting decision with the current project brief.

**Success criteria:** The answer combines both retrieved sources and preserves links you can check.

## Quick Check

What did the assistant assume? Which fact or behavior did you verify yourself?

## Carry Forward

Keep the verified connections and source links for Lesson 1.05. Connect Calendar, Granola, and Linear if you want to use all three in that activity.

## Tutor Notes

Offer setup help and act on the tools the learner chooses. Use a plugin when it supports the action; use the enabled computer/browser tools for setup when needed. Do not request broad account access or connect every listed service by default. Signing in and granting personal account consent remain learner steps. If the first lookup fails, troubleshoot that connection rather than claiming success.

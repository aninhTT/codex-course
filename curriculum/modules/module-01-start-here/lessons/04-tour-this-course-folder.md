# Lesson 1.04: Tour This Course Folder

## Where You Are

You have seen Codex inspect one file. Now you will zoom out and learn what is already inside the course folder you opened.

## Learn

This course folder is intentionally set up like a small Codex workspace. You do not need to open every file yourself to continue, but you should know what is here.

Codex can explain the folder structure in the chat while you also inspect the same folder wherever you opened it on your computer. That is the point: Codex is not asking you to imagine a workspace. It is looking at the one you are using.

## Visual Cue

```text
codex-course/
├── curriculum/          lessons, modules, and course assets
├── practice-workspace/  safe files and starter app for guided exercises
├── learner-assets/      tracker, use-case worksheet, and local skill files
├── reference/           cheat sheets, glossary, troubleshooting
└── playground/          experiments that are not part of the guided path
```

Screenshot slot: `curriculum/assets/screenshots/course-folder-navigation.png`

## Practice

Try this in Codex:

```text
Give me a beginner-friendly tour of this course folder. Explain what lives in `curriculum/`, `practice-workspace/`, `learner-assets/`, `reference/`, and `playground/`. Tell me what I should inspect on my own computer if I want to see the files directly. Do not edit anything.
```

**Success criteria:** Codex explains the main folders in chat and the learner understands that the course content, sandbox, references, and learner assets are all already here.

## What You Made Or Decided

You now know what is inside the course workspace and where to look when Codex mentions a folder.

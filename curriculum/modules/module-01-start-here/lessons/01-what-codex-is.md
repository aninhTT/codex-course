# Lesson 1.01: Set Up Codex For This Course

## Where You Are

You just opened the course folder in Codex. Before doing course work, it is worth checking a few settings so Codex feels comfortable, clear, and beginner-friendly.

## Learn

Codex is not just a chat box. It is an agentic workspace: it can chat with you, inspect files, use tools and connected apps when allowed, make edits when you approve them, build artifacts, and explain what it is doing along the way.

That does not mean you need to feel technical to use it. Codex can help with organizing notes, cleaning up drafts, comparing files, shaping workflows, building simple tools, and turning repeated work into reusable helpers.

For this course, the most useful mental model is: **Codex is an agent that can work with the files, tools, apps, and context you give it, inside boundaries you can review.**

Before you go further, check Settings. In the Codex app, settings can control things like personality, custom instructions, appearance, browser/tool access, and how much detail Codex shows. If you are non-technical, choose settings and instructions that make Codex explain work in plain language.

## Practice

Try this in Codex:

```text
I'm new to Codex. First, explain what Codex is as an agentic workspace, not just a chat tool. Then tell me which Codex settings or custom instructions I should check if I want a beginner-friendly, non-technical learning experience. Do not change any files.
```

**Success criteria:** Codex explains what it can do in plain language and uses examples from this course workspace instead of staying abstract.

## What You Made Or Decided

You have a clearer Codex mental model and know which settings to inspect before the course gets more hands-on.

# Curriculum Assets

This folder holds visual support for the course.

- `visuals/` is for diagrams, image notes, and reusable visual descriptions.
- `screenshots/` is for product screenshots that will be added as the course is polished.
- `videos/` is for planned course video slots and links to recorded walkthroughs.

Lessons should still make sense if a screenshot is not present yet. Use screenshot placeholders as reminders for the course author, not as required learner steps.

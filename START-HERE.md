# Start the Course in Work or Codex

Last updated: **Friday, November 6, 2026** (11/6/2026).

Choose the surface you want to use. Your tutor can teach the entire foundation in either one.

## In ChatGPT Work

For most employees who are not engineers, start here.

1. Open ChatGPT Work in the desktop app.
2. Give the task access to this course folder, or attach the course ZIP. Ask it to extract the ZIP if needed.
3. Paste the starter request below. The tutor will check that it can read the lessons before starting.

## In Codex

Choose Codex if you prefer it or expect to work with GitHub, code changes, or local app files.

1. Open this course folder as a project in Codex.
2. Paste the same starter request, or say “Start the course” when the tutor instructions are already loaded.
3. Stay in Codex for the foundation and optional technical lessons.

## Starter Request

```text
I want to take this course here. Find and read START-HERE.md and AGENTS.md in the course materials. If I attached a ZIP, extract it first. Check that you can read the course index and a lesson. Act as my course tutor, check for saved progress, and teach the lessons conversationally one activity at a time. Use this surface throughout unless I choose to switch. Start or resume the course.
```

If a cloud-only task cannot use a local feature, the tutor will help with that specific activity. You do not need to move the whole course.

## Resume Later

Stay in the same task and ask “Take me to the next lesson.” If starting a new task, provide the course and your saved `learner-assets/progress.json`.

For an uploaded course, download the latest progress file before leaving if you want to resume elsewhere. Your original ZIP does not update itself.

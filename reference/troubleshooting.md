# When an Activity Gets Stuck

## The Assistant Cannot Read a File

Ask which files it can actually access. Check the project and selected account. Attach a source or connect an approved service when needed. A link alone does not prove access.

Keep tutoring in your chosen Work or Codex surface. For an uploaded course, ask the tutor to extract the files and locate START-HERE.md. Bring a handoff note only when you choose to move elsewhere.

## GitHub or the Marketplace Will Not Open

Sign in with the intended company account. Check repository permission. Ask for access to `thumbtack/shared-skills` if needed. Never paste passwords or access tokens into chat.

Inspect the included Clean Draft copy with the tutor while you request access. Record the GitHub download as unfinished. See `reference/clean-draft-setup.md`.

## The Skill Is Missing

A downloaded folder is not proof of installation. Ask the tutor to check the installed skill list and supported setup. Confirm which version you are running.

You can explicitly read the skill instructions and run a guided practice from the files. Label that route honestly. A web task cannot assume it can use a standalone local skill.

## The Clean Draft Checker Cannot Run

The checker needs Python 3. Ask the tutor to check availability and report the error. Continue with manual review if necessary. Mark the automated check incomplete.

## Recording Is Unavailable

Thumbtack has enabled Computer Use for the intended learning environment. If the recording control is missing, check the desktop setup; recording currently requires macOS. Use reference/recording-help.md for a tested written walkthrough, then continue to the capture-to-draft activity. Do not call that a completed recording.

## The Schedule Did Not Run

Open Scheduled and inspect the task and latest run. Check timing, timezone, source access, and required skills. Local work needs the computer on and app running. Cloud tasks need their own accessible inputs and tools.

Pause a noisy or broken task while you fix and test it. Record the cause before resuming.

## Space, File Creation, or Sites Is Missing

Check the actual account and tool error. The tutor can help use the relevant view or available tool from Work or Codex. If the feature remains unavailable, create a useful document, outline, table, mockup, or plan and record the unfinished live step.

## Progress Did Not Save

Ask the tutor to locate the latest progress file and verify that it wrote the update. For uploaded courses, the saved file stays in that task's accessible files. Download it before moving to a new task. Your original ZIP does not update automatically. See reference/progress-guide.md.

## Someone Cannot Open Shared Work

Check the saved audience setting and their account. Page access and source-file access are separate. Site visitor access and editor access are separate. Inspect inherited access if available.

Do not widen access just to make a link work. Use the intended audience and the organization's rules.

## You Lost Your Place

Say “Summarize where I am before I stop.” Ask for the current lesson, actual output locations, unfinished checks, active schedules, and next step.

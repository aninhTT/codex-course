# Product Guide for Course Tutors

Checked against official OpenAI documentation on November 6, 2026. Account access, device support, and company policy still determine which controls a learner sees. Recheck current instructions when a control differs.

## Choose a Work Surface

Recommend Work for most non-engineering employees who want an agent to complete everyday tasks. Support Codex throughout the foundation as an equally valid course surface. Recommend Codex for technical work such as repository inspection and local app development.

The tutor runs in either surface. Give learners the startup route in START-HERE.md and verify that the assistant can read the course files. Do not assume an uploaded instruction file automatically configures the tutor.

[Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

## Projects and Context

Projects group related chats and sources. ChatGPT projects and local folder projects have different access. Do not assume that moving a conversation transfers local files.

[Projects and chats](https://learn.chatgpt.com/docs/projects)

## Skills

Skills save a method. Plugins can distribute skills and connected tools. Standalone local skills and plugin-bundled skills have different availability across surfaces. Verify installation and the invocation method.

[Skills and plugins](https://learn.chatgpt.com/docs/skills-and-plugins) · [Build skills](https://learn.chatgpt.com/docs/build-skills)

## Connected Tools

Thumbtack has enabled Computer Use in the intended learning environment. Offer practical setup help for the tools the learner chooses in Lesson 1.04. Google Drive may supply Docs, Sheets, and Drive together. Test actual retrieval after setup.

The learner completes personal sign-in and account-consent steps. Use available setup tools or browser help rather than merely listing missing connections.

[Plugins](https://learn.chatgpt.com/docs/plugins)

## Recorded Workflows

Record & Replay requires macOS and enabled Computer Use. Current desktop guidance uses Plugins → + → Record a skill. Stop recording, inspect the draft, and test with a new input.

[Record & Replay](https://learn.chatgpt.com/docs/extend/record-and-replay)

## Scheduled Tasks

Scheduled can show task settings and runs. Tasks can return to a chat or start fresh runs. Local file work needs the computer and app available. Cloud tasks need accessible uploads or connected sources and compatible tools.

The foundation teaches weekly or monthly draft preparation. Learners can explore event-triggered and team-owned tasks later; they are not prerequisites.

[Scheduled tasks](https://learn.chatgpt.com/docs/automations)

## Space and Collaboration

Space holds Pages and other work. A space groups related Pages. Copied content takes on the destination's visibility. Linked sources keep their own permissions. Check direct and inherited access before sharing.

[Space](https://learn.chatgpt.com/docs/space) · [Collaboration](https://learn.chatgpt.com/docs/space/collaboration)

## Work Files

Ask for the needed file type, structure, and review checks. Preview or open the generated document, deck, spreadsheet, or PDF and request targeted revisions.

[Work with files](https://learn.chatgpt.com/docs/artifacts-viewer)

## Sites

Sites can begin from a prompt or compatible local project. Saving a version differs from deployment. Every deployment URL is production, with access determined by its saved audience. Visitor access and editing rights differ.

[Create a Site](https://learn.chatgpt.com/docs/sites/creating-a-site) · [Publish and share](https://learn.chatgpt.com/docs/sites/publishing-and-sharing)

## Personalization and Longer Work

Distinguish preferences, required project rules, and memories. For longer work, name the outcome, constraints, and verification. Dedicated Goal controls depend on the surface.

Module 10 supports Work and Codex. It does not require the Codex building module. Keep the product's Goal controls distinct from ordinary requests that use the same completion criteria.

[Personalization](https://learn.chatgpt.com/docs/personalize) · [Get started with Work](https://learn.chatgpt.com/docs/get-started-with-work) · [Long-running work](https://learn.chatgpt.com/docs/long-running-work)

## Optional Everyday Tools

Voice, screenshots, browser tools, and interactive visualizations can help explain or review a task. Introduce them when useful rather than requiring another setup step.

[Using ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt) · [Browser](https://learn.chatgpt.com/docs/browser)

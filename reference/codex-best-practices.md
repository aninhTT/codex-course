# Good Habits for Everyday Work

## The Basic Loop

1. Ask for one useful result.
2. Check the sources and access.
3. Plan before a larger change.
4. Let the assistant do the agreed work.
5. Review the actual result.
6. Save the method if it repeats.

These habits apply in ChatGPT Work and Codex.

## Make the Work Easy to Check

Name the audience, sources, format, and review criteria. Keep missing information visible. Ask for a small revision when the first version misses the point.

Check facts separately from writing quality. Clean Draft can make a sentence clearer without proving the claim inside it.

Open the result where someone will use it: the document, spreadsheet, Page, or deployed Site. Do not rely only on the assistant's summary.

## Keep Context Manageable

Use a project for related work. Start separate chats for different outcomes. Keep source notes and generated outputs in separate places.

Keep recurring rules in project instructions or a skill. Use memory for helpful context, not as the only copy of a required rule.

When changing work surfaces, bring a source list and handoff note. Check access again. Do not assume another chat knows the conversation or can read the same files.

## Make Repeated Work Reliable

Test a skill with a second input. Check whether a recorded workflow needs your local apps. Test a scheduled task in its intended environment.

Schedule draft preparation first. Add shared destinations deliberately after testing and authorization. Pause course schedules you no longer need.

## Helpful Requests

```text
Explain what you can access before changing anything.
```

```text
Plan the result, sources, changes, and review steps before building.
```

```text
Make one focused change. Show what changed and what I should check.
```

```text
Summarize what exists, where it lives, what is unverified, and what I should do next.
```

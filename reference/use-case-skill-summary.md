# Optional Use-Case Discovery Skill

The older course used the included `use-case` skill as its main example. Clean Draft is now the foundation example in Module 3.

The discovery skill remains in `learner-assets/skills/use-case/` as optional source material. It can help identify repeated work from your answers or approved workplace sources. It is not required to complete the foundation.

Its source instructions may refer to other AI products. The tutor should explain the activity in current Work/Codex terms. Keep the original source package unchanged and inspect its requested access before using it.

Ask for an interview-only run if you do not want to connect workplace tools. Save ideas in `learner-assets/use-case-shortlist.md`.

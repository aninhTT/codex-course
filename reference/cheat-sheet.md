# Everyday Work Cheat Sheet

## Choose a Surface

Start with Work for most everyday employee tasks. Choose Codex if you prefer it or want technical tools for GitHub and app development. The foundation works in either surface.

| Need | Useful feature |
| --- | --- |
| Keep related work and sources together | Project. |
| Read or act in your work tools | Connected plugin. |
| Save a repeatable method | Skill. |
| Improve structure and wording | Clean Draft. |
| Create a new workflow skill | Skill Creator. |
| Demonstrate repeated computer steps | Record & Replay. |
| Run a tested request weekly or monthly | Scheduled task. |
| Keep a living document | Page in Space. |
| Build a team hub or small web app | Site. |
| Inspect local code changes | Codex building path. |
| Guide longer work to a checkable finish | Goal or bounded Work task. |

## A Useful Request

“Create [result] for [audience]. Use [sources and period]. Follow [format]. Flag missing information. Save it in [place].”

## Review Before Sharing

Check the facts, intended reader, and requested action. Cut unnecessary material. Use the current [AI Expectations](https://thumbtack.haystack.so/resources/c8602dcc-0898-4f92-ae93-243ee7d696ba) and own the result.

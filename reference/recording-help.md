# When Recording Needs Help

Thumbtack has enabled Computer Use in the intended learning environment. If Record a skill is missing, check the actual desktop setup. Recording currently requires macOS; Computer Use availability alone does not establish recording support.

## A Useful Written Route

1. Describe the start screen and sample input.
2. List each action, including any choice you make.
3. Name the values that change on another run.
4. Describe the expected saved result and how to check it.
5. Ask Skill Creator to turn the walkthrough into a skill draft.
6. Test it with a different sample input using available tools or a manual walkthrough.

Record this as a written walkthrough and note any untested actions. Continue with the capture-to-draft activity in Lesson 4.04. A written walkthrough is not a completed recording.

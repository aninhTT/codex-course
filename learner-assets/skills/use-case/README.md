# Use-Case Skill

This is the local course copy of the `use-case` skill used in Module 3.

The source files were copied into the course so learners do not need GitHub access during the lesson.

## Course Note

The original skill was written for a broader AI workflow environment and may mention Claude/Cowork in source files. In this course, use it as a Codex learning asset: ask Codex to read `SKILL.md`, run the use-case discovery process conversationally, translate those references into Codex course language, and save the course-facing output to `learner-assets/use-case-shortlist.md`.

Keep connector access optional and consent-based. Learners can run the skill using only their own answers if they do not want Codex to inspect connected apps.

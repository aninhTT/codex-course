# Artifact Tracker

Use this file as the learner's lightweight checklist. It is here to help the learner keep their place, not to run the course for them.

## Module 0

- [ ] I understand what this course is and what I will build.
- [ ] I know where the reference docs live.
- [ ] I understand the four course agreements.
- [ ] I know how to ask for the outline, the next step, or a specific module in plain language.

## Module 1

- [ ] I checked the Codex settings that affect tone, preferences, and comfort level.
- [ ] I can explain Codex as an agent that can act with files, tools, apps, and context.
- [ ] I can explain when Codex is a better fit than chat-only help.
- [ ] I completed a first read-only task and course folder tour using practice files.

## Module 2

- [ ] I can explain that a Codex project is basically a local folder with context.
- [ ] I know what is inside the course folder and where to inspect it on my computer.
- [ ] I know that most course work happens in this course folder, while real work can later move to its own local folder.
- [ ] I asked Codex to inspect before editing.
- [ ] I asked Codex to make a small change and reviewed it.
- [ ] I created my own notes file in the practice workspace.

## Module 3

- [ ] I can explain the difference between a one-off prompt, a repeatable process, and a skill.
- [ ] I understand a skill as a repeatable process Codex can follow with tools, references, and scripts when needed.
- [ ] I inspected the local `use-case` skill.
- [ ] I ran the local `use-case` skill and saved 3 to 5 practical ideas.
- [ ] I built a first practical skill from the shortlist or course fallback.
- [ ] I chose one workflow to turn into a custom skill.
- [ ] I had Codex ask several narrowing questions to capture the workflow clearly.
- [ ] I built, tested, and refined a custom workflow skill.

## Module 4

- [ ] I can explain what a prototype is for.
- [ ] I chose whether to build a suggested pain-point prototype or the starter app.
- [ ] I toured the starter app and understood its basic files.
- [ ] I made one guided prototype change.
- [ ] I wrote my own prototype prompt using guiding questions.
- [ ] I used Plan mode before building.
- [ ] I built, previewed, reviewed, and summarized my prototype work.
- [ ] I completed the visual checkpoint before moving into Goals.

## Module 5

- [ ] I can explain when a normal prompt is enough and when a Goal is useful.
- [ ] I can name the parts of a strong Goal.
- [ ] I improved a rough Goal before deciding whether to run it.
- [ ] I drafted one bounded, evidence-backed Goal.
- [ ] I understand that Goals are for longer-horizon, evidence-checked work.

## Module 6

- [ ] I chose one professional pain point for my basics capstone.
- [ ] I assembled a Codex Workflow Starter Kit.
- [ ] I created a review checklist and next-step map.
- [ ] I know when this work should stay in the course folder and when it deserves its own project folder.

## Module 7

- [ ] I chose a workflow that is a good candidate for recording.
- [ ] I prepared a clean recording plan with no secrets or unrelated cleanup.
- [ ] I refined a recorded skill or drafted a recording-level workflow walkthrough.
- [ ] I named variable inputs, hidden preferences, success checks, and stop conditions.

## Module 8

- [ ] I reviewed my local prototype as a possible hosted site.
- [ ] I created a Sites-readiness checklist.
- [ ] I checked access, secrets, environment values, and storage needs.
- [ ] I deployed a Codex Site and saved the URL.
- [ ] I can explain local preview, saved version, and deployment.

## Module 9

- [ ] I can compare normal prompt loops, review loops, Goal loops, thread automations, and standalone automations.
- [ ] I chose the safest recurring pattern for one workflow.
- [ ] I drafted a durable automation prompt.
- [ ] I created an automation design card.
- [ ] I manually tested the automation idea.
- [ ] I scheduled one safe read-only or report-only recurring loop.

## Module 10

- [ ] I created a compounding workflow system map.
- [ ] I reviewed the system for risks, missing evidence, privacy concerns, and overbroad automation.
- [ ] I chose what should become a skill, automation, small tool, Site, or review habit next.

## Module 11

- [ ] I completed the course.
- [ ] I reviewed next-step learning resources.

## Final Reflection

- What task do I want Codex to save me time on every week?
- Which artifact will I keep improving first: notes file, use-case shortlist, first skill, custom skill, prototype, Goal, recorded workflow, Sites URL, scheduled loop, or workflow starter kit?
- What kind of work still feels confusing enough that I want Codex to tutor me through it?

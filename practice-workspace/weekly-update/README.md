These materials are fictional. Use them throughout Modules 1–8.

| File | Use |
| --- | --- |
| `week-01-notes.md` | First update and Clean Draft comparison. |
| `week-02-notes.md` | Second input for testing your own skill. |

Keep these inputs unchanged. Save generated work in `practice-workspace/outputs/` or your chosen project. Do not let a scheduled task read old generated updates as new source notes.

The notes leave some details unknown on purpose. Flag them rather than inventing a name, date, number, or decision.

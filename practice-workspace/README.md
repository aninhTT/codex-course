# Practice Workspace

Use this folder for guided activities. The sources are fictional so you can begin without sharing real work information.

- `weekly-update/`: notes, template, and data for the foundation workflow.
- `outputs/`: generated drafts, work files, run cards, and maps.
- `downloads/`: the complete Clean Draft folder you retrieve in Lesson 3.02, when available.
- `starter-app/`: a local app for optional Module 9.
- `notes/`, `templates/`, `inbox/`, and `projects/`: additional sample material for side practice.
- `reference/`: a pointer to course explanations.

Inspect sources before editing. Keep notes separate from outputs. Use `playground/` for experiments or the optional prototype copy. Check your project and file locations before acting.
